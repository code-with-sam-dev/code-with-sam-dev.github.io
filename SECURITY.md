# Security

This is a static site. It has no server, no database, no user accounts and no
form that submits anywhere, so the attack surface is small by construction.

If you find something anyway, for example a dependency advisory that affects the
build, or a way to inject content into a published page, please report it
privately through GitHub's
[security advisory form](https://github.com/code-with-sam-dev/code-with-sam-dev.github.io/security/advisories/new)
rather than opening a public issue.
